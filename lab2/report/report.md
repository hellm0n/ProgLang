### Задание 2

**C++:** `синтаксическая ошибка: отсутствие ";" перед идентификатором "b"`

**Python:** ошибок нет

**Последовательность токенов C++:**
[int] [c] [=] [a] [++] [b] [;]

**Последовательность токенов Python:**
[c] [=] [a] [+] [+] [b]

в c++ ошибка, т.к. `++` - оператор инкремента (унарный). в примере он относится к `a`, но сразу после него идёт переменная `b`, что ломает структуру выражения. А в python инкремента нет, поэтому `++` эквивалентен простому `+`.

### Задание 3

**[int] [c] [=] [a] [++] [+] [b] [;]** - `c` будет равно 3 после выполнения. здесь происходит постфиксный инкремент `a`, а затем сложение с `b`. Постфиксный инкремент увеличит значение переменной только после выражения, поэтому в рамках этого сложения `a` остаётся равной 1. Чтобы инкремент сработал сразу нужно использовать префиксный вариант: `++a`.

### Задание 5

* Ключевые слова: `for`, `in`
* Литералы: `1`, `2`, `3` (целочисленные литералы внутри кортежа)
* Операторы: `*` (оператор распаковки аргументов)
* Идентификаторы:
  * Переменные: `i`
  * Имена функций и методов: `print`, `map`, `sum`, `zip`, `int`, `input`, `split`

**Вызываемые функции, методы и их параметры:**
* `input()` - считывает строку текста из консоли
* `split()` - разделяет считанную строку на список отдельных строк
* `int` - приведение ввода к целому числу
* `map(int, <строки>)` - преобразует в целые числа
* `zip()` - группирует элементы с одинаковыми индексами
* `sum` - встроенная функция, считает сумму элементов
* `map(sum, zip)` - применяет сумму к каждому сгруппированному столбцу
* `print()` - выводит результат работы map

**Что делает эта программа и как получается результат?**

* Генератор списков [... for i in (1,2,3)] запускает цикл ровно 3 раза.
* На каждом шаге цикла input().split() считывает строку и разбивает её на отдельные элементы.
* map(int, ...) превращает эти строки в числа: [10, 20, 30]. В итоге после цикла мы получаем список из трех списков **3 x N**.
* Оператор * перед списком раскрывает его. То есть вместо одного списка [[строка1], [строка2], [строка3]] в функцию zip передаются три отдельных списка как три параметра.
* zip(...) транспонирует матрицу — склеивает первый элемент с первым, второй со вторым и т.д. Из строк получаются столбцы.
* map(sum, ...) берёт каждый получившийся столбец и складывает все числа в нём.
* print(*...) выводит эти суммы в консоль одной строкой через пробел.

### Задание 6

**Вызовут ошибку:**
``` cpp
// /*
 Это комментарий
*/
```
Потому что `/*` закомментировано через `//`

---
``` cpp
/* Я комментирую программы /* комментарий */ */
```
Потому что комментарий закрывается дважды

---
``` cpp
/* Я комментирую свои программы
// Это комментарий до конца строки */
*/
```
Потому что `//` начинает игнорировать всё, кроме закрытия комментария, поэтому в этой же строке многострочный комментарий заканчивается, а на следующей строке ошибка

### Задание 7

* **Цикл с предусловием**
    * **Формат записи:** ключевое слово `while`, в круглых скобках необязательный список выражений или объявление условия `<expression-list_opt>`, далее инструкция `<<statement>>`
  * **Пример кода:**
    ``` cpp
    int x = 1;
    while (x < 1000) {
        cout << x;
        x *= 2;
    }
    ```
* **Цикл с постусловием**
    * **Формат записи:** ключевое слово `do`, тело цикла в виде инструкции `<<statement>>`, затем ключевое слово `while`, в круглых скобках обязательное выражение-условие `<expression>`, в конце точка с запятой `;`
  * **Пример кода:**
    ``` cpp
    int x = 1;
    do {
        cout << x;
        x *= 2;
    } while (x < 1000);
    ```
* **Цикл с счётчиком**
    * **Формат записи:** ключевое слово `for`, в круглых скобках инструкция инициализации `<for-init-statement>`, затем необязательный список выражений условия `<expression-list_opt>`, точка с запятой `;`, необязательное выражение шага цикла `<expression_opt>`, далее инструкция тела цикла `<<statement>>`
  * **Пример кода:**
    ``` cpp
    for (int i = 0; i < 10; ++i) {
        cout << i << " ";
    }
    ```
* **Диапазонный цикл**
    * **Формат записи:** ключевое слово `for`, в круглых скобках объявление переменной диапазона `<for-range-declaration>`, двоеточие `:`, инициализатор диапазона (коллекция/массив) `<for-range-initializer>`, далее инструкция тела цикла `<<statement>>`
  * **Пример кода:**
    ``` cpp
    vector<int> v = {1, 2, 3};
    for (int x : v) {
        cout << x << " ";
    }
    ```
