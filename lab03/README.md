*Составьте глоссарий из определений лекции. Проверка отчета будет включать

* **Тип в программировании**
* **Статическая типизация**
* **Динамическая типизация**
* **Неявная типизация**
* **Явное преобразование типа**
* **Неявное преобразование типа**

* **Слабая типизация**

**Ответ:**

* **Тип в программировании** — характеристика данных, которая определяет, какие значения может хранить переменная

* **Статическая типизация** — тип переменной определяется во время компиляции программы и не изменяется во время её выполнения

* **Динамическая типизация** — тип значения определяется во время выполнения программы. Переменная может в разное время ссылаться на значения разных типов

* **Неявная типизация** — тип переменной или выражения определяется автоматически без явного указания типа программистом

* **Явное преобразование типа** — преобразование значения из одного типа в другой, которое указывается самостоятельно

* **Неявное преобразование типа** — автоматическое преобразование одного типа в другой

* **Сильная типизация** — свойство языка, при котором операции между несовместимыми типами запрещаются или требуют явного преобразования

* **Слабая типизация** — свойство языка, при котором язык допускает автоматические преобразования типов

### Задание 2 **(3)**

*Запишите правила неявного преобразования типов в языке С++*

*Проверка отчета будет включать проверку знания правил.*

*Преобразования при присваивании*

*Преобразования при арифметических действиях*

*Преобразования с логическими значениями*

**Ответ:**

При присваивании значение правой части преобразуется к типу переменной слева, если такое преобразование разрешено

При присваивании целого числа вещественной переменной выполняется обратное преобразование

Также при необходимости выполняются преобразования между знаковыми и беззнаковыми целыми типами

Перед выполнением арифметической операции C++ приводит операнды к совместимому типу.

Основные правила:

1. `bool`, `char`, `signed char`, `unsigned char` и `short` обычно сначала продвигаются до `int`.
2. Если один из операндов имеет тип `unsigned int`, а другой — `int`, то обычно оба приводятся к `unsigned int`.
3. Если участвует `long`, типы приводятся к `long` или `unsigned long` в зависимости от знаковости.
4. Если участвует `long long`, используется `long long` или `unsigned long long`.
5. Если участвует вещественный тип, целые значения преобразуются к вещественному типу. Например, при операции `int + double` значение `int` преобразуется в `double`.

При использовании значения в логическом контексте:
* `0` преобразуется в `false`;
* любое ненулевое значение преобразуется в `true`.

При преобразовании `true` в целое число получается `1`, а `false` преобразуется в `0`.


### Задание 7. **(2)**

*Рассмотрите следующий фрагмент программы.*

```
int x = 7, y = 4; 
long double d = 0.25; 
cout << (x / y) / d << endl; 
cout << (x / d) / y << endl; 
long a = 200000, b = 200000; 
long long c = 200000; 
std::cout << (a * b) * c << std::endl; 
std::cout << a * (b * c) << std::endl; 
```

*Почему изменения порядка действий приводит
к изменению результата? Объясните работу этой программы, используя правила неявного преобразования типов*

**Ответ:**

В первом выражении сначала выполняется целочисленное деление:

```cpp
7 / 4 = 1
1 / 0.25 = 4
```

Во втором `x` сразу преобразуется в `long double`:

```cpp
7 / 0.25 = 28
28 / 4 = 7
```

Поэтому результаты разные: **4 и 7**.

Во второй части сначала вычисляется `a * b` в типе `long`. Если `long` 32-битный, возможно переполнение.

`b * c` выполняется в `long long`, поэтому промежуточный результат имеет больший диапазон.
